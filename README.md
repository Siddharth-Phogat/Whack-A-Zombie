# 🧟 Whack-A-Zombie

A spooky, fast-paced browser game built with **HTML**, **CSS**, and **JavaScript**. Test your reflexes by clicking zombies, avoiding humans, and surviving creepy jumpscares!

---

## 🎮 Gameplay Overview

- **🧟 Zombies**: Click to score 10 points each.
- **🧍 Humans**: Avoid clicking or you’ll lose a life.
- **👻 Jumpscares**: Randomly appear to keep you on edge.
- **⏱️ Timer**: You have 60 seconds to play.
- **❤️ Lives**: You start with 3 lives. Lose them all, game over.
- **🎯 Score 500 to win!**

---

## 🌟 Features

- Toggle **Dark Mode** for limited visibility with fog effects.
- Toggle **Gun Mode** to enhance gameplay visuals.
- **Flicker Mode** adds flickering effects for a more intense experience.
- **Game Over screen** with final score and replay button.
- Smooth animations and **atmospheric sound effects**.

## How to Run Locally

1.  Clone the repository:git clone [https://github.com/your-username/whack-a-zombie.git](https://github.com/your-username/whack-a-zombie.git)
    
2.  Navigate into the project folder:cd whack-a-zombie/code
    
3.  Open index.html in your browser.

No installation required. Just open and play!
